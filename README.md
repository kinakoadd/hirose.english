英語に特化した 個別指導塾
英語だけに集中
「英語だけは広瀬英語塾で」と選んでもらえる塾です。ほかの教科は学校や別の塾で、英語はここで。通ううちに英語への苦手意識が薄れます。
得点につながる指導
生徒の理解度を見極め、点数に直結するポイントを押さえて教えます。 宿題・定期テスト・入試・検定まで柔軟に対応します。
自力で解く方法を教える
答えを教えるだけでなく、自分で解くための考え方と手順を身につける授業です。身につけた方法は、この先の 学びを支えます。
